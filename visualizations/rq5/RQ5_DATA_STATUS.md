## 实验设计说明

### 当前实验方法

**Baseline**: 
- 完整模型（Attention ✓ + MLP完整 ✓）

**V-Ablated**:
- 完整模型（Attention ✓ + MLP的V矩阵被随机正交矩阵替换 ⚠️）

### V矩阵消融方法

```
原始: W = U Σ Vᵀ
消融: W' = U Σ V'ᵀ (V'是随机正交矩阵)
```

**优点**: 
- 保持权重维度不变
- 测试V矩阵的语义方向作用

**适用范围**: 
- 所有标准MLP结构
- 已验证对6/7模型有效
