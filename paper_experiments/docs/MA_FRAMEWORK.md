# MA 完整框架（定型版）

## 总览：三部分结构

```
┌─────────────────────────────────────────────────────┐
│  I. 生成部分 (Generation)                              │
│     MA 是怎么产生的                                    │
│     → 2 种模式（独立分类）                              │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│  II. 传递部分 (Transmission)                           │
│     MA 怎么传到各层各位置                              │
│     → 3 个通道（所有模型通用）                          │
└─────────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────┐
│  III. 调节部分 (Regulation)                            │
│     MA 怎么保持稳定（不爆炸不崩溃）                     │
│     → 4 种机制（不同模型组合不同）                      │
└─────────────────────────────────────────────────────┘
```

**核心原则**：生成和调节是**两个独立的维度**，可以自由组合。MLP 既参与生成（某些层），也参与调节（其他层）。

---

## I. 生成部分

按训练动力学解释。

### 训练动力学起源

```
训练初期：
  Function word 易学习（高频 + 低熵 + 任务简单）
  ↓
  Loss 快速下降（功能词预测变准）
  ↓
  梯度推动 MLP 在功能词位置写入大激活
  ↓
  MA 形成
```

### 两种生成模式（**真实存在的不同模式**）

#### 模式 A：单层主导生成
```
1-2 个早期 MLP 层完成全部 MA 生成
其他层仅微调或无关
```

**判定标准**：存在某个层 ablation 后 MA 下降 ≥ 85%

**例子**：
- GPT-J（L1+L2 主导，L1 -89%, L2 -90%）
- BLOOM（L3 主导，-95%）
- Falcon（L3 主导，-87%）
- Qwen2.5-0.5B（L0 主导，-90%）

#### 模式 B：多层协作生成
```
5+ 层 MLP 共同贡献，每层小幅
跨层方向一致（u₁ alignment > 0.7）
合起来形成 MA
```

**判定标准**：所有单层 ablation 都 < 30%，且 macro-SVD 显示同向聚合

**例子**：
- GPT-2（L0-L4，每层最多 -6.7%，u₁ 对齐 0.856）

### 关键区别

```
模式 A（单层主导）：
  ablation L_origin → MA 大降
  ablation 其他层 → MA 几乎不变

模式 B（多层协作）：
  ablation 任何单层 → MA 小降
  ablation 多层组合 → MA 大降（贪心消融）
```

**不能把模式 B 简化为"模式 A + 调节"**——它们是真实不同的生成模式。

---

## II. 传递部分（所有模型通用）

MA 一旦生成，通过 3 个通道传递。

### 通道 1：残差流（核心）

```
h_{L+1} = h_L + Attn(h_L) + MLP(h_L)
```
- MA 写入残差后，自动垂直传到下一层
- transformer 架构的天然属性
- 所有模型通用

### 通道 2：Attention sink + carry（横向）

```
当 attention 看到 MA token：
   Step 1 (sink): 大量注意力权重集中到 MA 位置
   Step 2 (carry): 读取 MA token 的 V 向量
   Step 3 (write): 把信息写到其他 token 位置

→ MA 信号横向传播到整个序列
```

不只是层间垂直传递，也是 token 间横向传递。

### 通道 3：LayerNorm 保形性（保护）

```
LayerNorm 归一化 hidden state
→ 表面上"压平"了大值
→ 但 MA 维度仍是相对最大
→ 下游计算仍能识别
```

被动保护：归一化不消除 MA 的相对显著性。

### 三通道协同

```
残差流: 跨层垂直传递
Attention: 跨 token 横向传递
LayerNorm: 归一化下保护

→ MA 形成"立体可达"网络
→ 任何位置任何层都能"看见" MA 信号
```

## III. 调节部分（不同模型用不同组合）

**假设**：训练好的模型必须同时满足：
- 可计算性（数值不溢出、梯度不爆炸）
- 信息保留（MA 存在但不淹没语义）
- 跨任务通用（适应不同文本）

→ 必须有调节机制防止 MA 失控。

### 4 种调节机制（独立可叠加）

#### 机制 1：MLP 内部调节
```
某些 MLP 层主动"减少" MA
（输出在 MA 维度上为负）

特征:
  ablation 该层 → MA 反而增加

例子:
  GPT-J L0: ablation 后 MA 4548 → 6572 (+44%)
  说明 L0 的 MLP 在主动抑制 MA
```

**MLP 不只是生成器，部分层是调节器**。

#### 机制 2：Attention 抑制（suppressive 模式）
```
某些 attention head 在 MA 位置输出负值
直接抵消 MLP 写入的 MA

特征:
  ablation attention → MA 暴涨

例子:
  OPT-6.7B: +250%
  Qwen2.5-7B: +266%
  Qwen2-7B: +∞
```

7/25 模型有 suppressive attention。

#### 机制 3：LayerNorm 归一化（被动硬约束）
```
LayerNorm 把 hidden state 总尺度归一化
→ 限制 MA 的绝对增长上限
→ 不能让 MA 无限增长

特征:
  所有模型都有
  是架构层面的约束
```

#### 机制 4：GELU 软门控（MLP 内部节流）
```
GELU(x) = x · Φ(x)
  对超大输入: 接近线性放大
  对超小输入: 接近零
  对中等: 平滑过渡

→ 防止某个维度被无限放大
→ MLP 内部的"自动节流阀"
```

### 调节机制可独立组合

不同模型采用不同的调节组合：

| 模型 | MLP 调节 | Attn 抑制 | LayerNorm | GELU | 总调节强度 |
|------|:----:|:----:|:----:|:----:|:----:|
| GPT-J | ✓ (L0) | ✗ | ✓ | ✓ | 中 |
| GPT-2 | ? | ✗ | ✓ | ✓ | 弱（靠多层分散）|
| Qwen2.5-7B | ? | ✓✓ | ✓ | ✓ | 强 |
| OPT-6.7B | ? | ✓✓ | ✓ | ✓ | 强 |

LayerNorm 和 GELU 是通用的（每个模型都有）。
MLP 调节和 Attn 抑制是可变的。

## 完整框架的核心洞察

```
1. 生成是因为训练初期 function word 易学
   → 模式 A (单层主导) 或 模式 B (多层协作)

2. 传递通过架构天然机制
   → 残差流 + attention + LayerNorm 三通道
   → 所有模型相同

3. 调节是后期为了模型功能正常
   → MLP 调节 + Attn 抑制 + LayerNorm + GELU
   → 不同模型不同组合

4. MLP 同时参与生成和调节
   → 起源层生成
   → 其他层可能调节
```

## 训练动力学验证（Pythia-160M 实测数据）

### 实测 MA 演化曲线

```
Step      Top1 MA    倍数      阶段
─────────────────────────────────────────
1         2.1        1×        Phase 0: 无 MA（随机初始化）
1,000     3.5        1.7×      Phase 1: 萌芽
8,000     233.6      111×      Phase 1: 加速增长
32,000    622.0      296×      Phase 1: 达峰值
143,000   293.0      140×      Phase 2: 回落稳定（调节生效）
```

### 验证了什么

1. **MA 是训练产物**：初始 MA = 2.1（噪声级），训练后增长 300 倍 ✓
2. **先涨后降**：step 1→32k 增长 300×，step 32k→143k 降回 50% ✓
3. **不会消失**：最终 293 仍是初始的 140 倍 ✓

### 完美对应理论预测

```
理论预测                               实测
─────────────────────────────────────────────────
Phase 1: function word 易学 → MA 增长    step 1→32k: 2.1 → 622  ✓
Phase 2: content 学习 → 学会调节         step 32k→143k: 622 → 293  ✓
MA 不消失（已成基础设施）                最终 293 >> 2.1  ✓
```

### Peak layer 的迁移

```
Step 1:      peak at L9（深层）
Step 1000:   peak at L11（深层）
Step 8000:   peak at L7（浅层）
Step 143000: peak at L7（浅层）
```

训练初期 MA 在深层，后期迁移到浅层。说明起源层位置也是训练过程中逐步确定的。

## 一句话总结

> **MA 由 MLP 生成（两种模式：单层主导 or 多层协作），通过残差流 + attention + LayerNorm 三通道传递，由 MLP 调节、attention 抑制、LayerNorm、GELU 四种机制保持稳定。**
>
> **生成模式和调节组合是独立的两个维度，不同模型呈现不同组合。**
>
> **MLP 不只是生成者，部分层也是调节者。**
