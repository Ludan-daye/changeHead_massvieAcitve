# MA 论文核心发现 + 实验完成度追踪

## 发现 1：理论解释 - 为什么功能词上会有 MA

详见 `MA_WHY.md`（15 章理论分析）。

**核心论点**：MA 是训练动力学的必然产物，不是设计出来的。

**理论支柱**：
1. **训练核心矛盾**：模型需要同时完成"快速预测高频词"和"长程保留语义"两个冲突任务
2. **功能词的语言学特性**：高频 + 低熵 + 低维度语义 → 适合作为结构标签载体
3. **维度复用**：在功能词的"空闲维度"上写入大激活作为标记，不破坏语义
4. **架构正反馈**：softmax 指数敏感 + LayerNorm 保形性 + 残差流持久性 → MA 一旦形成就稳定
5. **MLP-Attention 反馈环**：MLP 生成、attention 调节（利用或抑制）

**6 个角色**（基于实验验证）：
- 句法骨架路标
- Attention 导航灯
- 跨层广播台
- 信息分轨机制
- 能量调节基础线
- 计算资源优化

**完成度**：理论框架完整建立 ✓

## 发现 2：MLP 是 MA 的产生源头（含两种子模式）

```
【发现 1】MA 由 MLP 产生（共同前提）
   ├── 子模式 1.1：单层集中
   │   一个早期 MLP 一次性写入完整 MA
   │   
   └── 子模式 1.2：多层聚合
       多个 MLP 同向接力，合并为"虚拟整体"
       可用宏观 SVD 像分析单层一样分析
```

### 共同前提的子实验

| 子实验 | 测什么 | 目的 |
|--------|------|------|
| RQ1 (exp1) | 禁用 attention | 排除 attention 是来源 |
| RQ2a | 禁用全部 MLP | 确认 MLP 是来源 |
| RQ2b (exp2) | 逐层禁用 MLP | 区分 1.1 还是 1.2 |

**判定标准**：
- 单层 ΔMA > 85% → 子模式 1.1（单层集中）
- 单层 ΔMA < 30% → 子模式 1.2（多层聚合）
- 30%-85% → 中间形态

### 子模式 1.1 专属实验

| 子实验 | 测什么 | 论证什么 |
|--------|------|----------|
| RQ4 | 单层 W₂ SVD | v₁ 方向 + 投影 → MA |
| RQ5 | 单层 v₁ 消融 | v₁ 因果必要 |

### 子模式 1.2 专属实验

| 子实验 | 测什么 | 论证什么 |
