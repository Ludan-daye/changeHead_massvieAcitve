## 数据集下载方式

### 英文文本（4 种）

| 数据集 | 大小 | 下载方式 |
|--------|------|---------|
| WikiText-2 | ~12MB | `datasets.load_dataset('wikitext', 'wikitext-2-raw-v1')` |
| C4 (验证集) | ~360MB | `datasets.load_dataset('allenai/c4', 'en', split='validation')` |
| PG-19 | ~500MB | `datasets.load_dataset('emozilla/pg19', split='validation')` |
| RedPajama Sample | ~1.5GB | `datasets.load_dataset('togethercomputer/RedPajama-Data-1T-Sample')` |

HuggingFace 页面：
- https://huggingface.co/datasets/Salesforce/wikitext
- https://huggingface.co/datasets/allenai/c4
- https://huggingface.co/datasets/emozilla/pg19
- https://huggingface.co/datasets/togethercomputer/RedPajama-Data-1T-Sample

### 多语言文本（4 种）

| 数据集 | 语言 | 大小 | 下载方式 |
|--------|------|------|---------|
| cc100-zh | 中文 | ~50GB（取子集即可） | `datasets.load_dataset('cc100', lang='zh-Hans')` |
| cc100-ar | 阿拉伯语 | ~20GB（取子集即可） | `datasets.load_dataset('cc100', lang='ar')` |
| cc100-ja | 日语 | ~30GB（取子集即可） | `datasets.load_dataset('cc100', lang='ja')` |
| cc100-fr | 法语 | ~40GB（取子集即可） | `datasets.load_dataset('cc100', lang='fr')` |

HuggingFace 页面：
- https://huggingface.co/datasets/cc100

实际使用时只需取前 500 条文档（与 RedPajama 采样策略一致），不需要下载全量。代码示例：
```python
ds = datasets.load_dataset('cc100', lang='zh-Hans', split='train', streaming=True)
docs = list(itertools.islice(ds, 500))
```

### 视觉数据（2 种）

| 数据集 | 大小 | 下载方式 |
|--------|------|---------|
| ImageNet (ILSVRC2012 验证集) | ~6.3GB | 需手动下载，注册后获取 |
| COCO 2017 验证集 (自然图片) | ~800MB | 直接下载 |

下载链接：
- ImageNet: https://image-net.org/download.php （需注册）
- COCO 2017 val: http://images.cocodatasets.org/zips/val2017.zip

```bash
# COCO 下载
wget http://images.cocodatasets.org/zips/val2017.zip
unzip val2017.zip -d data/coco_val2017/

# ImageNet 需要先在 image-net.org 注册，下载 ILSVRC2012_img_val.tar
```
