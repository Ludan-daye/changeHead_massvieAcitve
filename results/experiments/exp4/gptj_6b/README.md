# GPT-J-6B Experiment 4: SVD Analysis

## 实验目的
对MLP fc_out权重进行SVD分析

## 方法
对Layer 0和Layer 27的`mlp.fc_out`权重矩阵进行SVD分解：
- W = UΣVᵀ
- 分析奇异值分布和主导方向

## 核心结果

| Layer | Shape | σ₁ | σ₂ | σ₁/σ₂ |
|-------|-------|-----|-----|-------|
| 0 | (4096, 16384) | 6.35 | 3.33 | 1.91 |
| 27 | (4096, 16384) | 27.53 | 15.19 | 1.81 |

### 奇异值分布
- Layer 0 Top5: [6.35, 3.33, 2.71, 2.57, 2.46]
- Layer 27 Top5: [27.53, 15.19, 8.80, 7.98, 7.45]

## 结论

1. σ₁/σ₂比值约1.9，表明有一个相对主导的方向
2. Layer 27的奇异值更大，但比值相近
3. 需要进一步测试与MA的对齐程度（见exp4b）
