# BLOOM-7B1 Experiment 6: V矩阵消融实验

## 方法
消融MLP down_proj的右奇异矩阵V，对比MA变化

## 核心结果

### 不同层V消融对比

| 层 | Baseline MA | 消融后MA | 变化 |
|----|-------------|----------|------|
| **Layer 0** | 92.5 | 27.0 | **-70.8%** |
| **Layer 28** | 320.2 | 275.2 | **-14.1%** |

### 各层MA值

| Layer | MA值 |
|-------|------|
| L0 | 92.5 |
| L1 | 119.6 |
| L10 | **3286.0** (最大) |
| L15 | 3352.0 |
| L20 | 3340.0 |
| L28 | 320.2 |

## 分析

### 为什么L28消融V影响小？

```
L28结构:
                 ┌─────────────────────────────┐
                 │   Residual (包含已有MA)      │
                 └──────────────┬──────────────┘
                                │
Input(含MA) → LN → Attn+MLP → + → Output
                     │         ↑
              (V控制这部分)  (residual直通)
```

- **Residual里的MA不受V影响**（直接跳过MLP）
- **消融V只破坏MLP的增量贡献**
- L28的MA主要来自residual传递，不是当层MLP产生

### 为什么L0消融V影响大？

- L0是MA的**产生层**
- 没有前面层的residual可依赖
- V直接控制MA的产生

## 结论

BLOOM的V依赖性弱(-18.8%)是因为：
1. 关键层在L28(后期层)
2. MA通过residual从早期层传递
3. 消融L28的V只影响增量，不影响已有MA

若消融L0的V，影响达**-70.8%**，与其他模型一致。
