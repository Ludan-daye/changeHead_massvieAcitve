# 实验4b: SVD对齐测试

## 实验目的
测试SVD主导方向(u1)与实际Massive Activation向量的对齐程度

## 实验方法
1. 计算指定层MLP down_proj的SVD，获取u1
2. 收集该层的实际激活向量
3. 计算余弦相似度

## 核心结果

### Layer 0（关键层）
| 指标 | 值 |
|------|-----|
| σ₁/σ₂ | 1.08 |
| 与u1对齐 | **0.017** |
| 与u2对齐 | 0.051 |

### Layer 31（抑制层）
| 指标 | 值 |
|------|-----|
| σ₁/σ₂ | 1.77 |
| 与u1对齐 | **0.279** |
| 与u2对齐 | 0.213 |

### 关键维度分析
| Dim | u1值 | 激活值 |
|-----|------|--------|
| 3901 | **-0.81** | **15.76** |
| 2070 | 0.49 | 10.75 |

## 结论（更新）

### Layer 0: 中等对齐（cos=-0.38）
| MA维度 | 激活值 | u1值 |
|--------|--------|------|
| Dim 1437 | 0.051 | **-0.27** |
| Dim 2070 | 0.045 | **0.45** |
| Dim 3398 | 0.041 | **0.31** |

→ Top MA维度在u1中有显著值，存在对齐

### Layer 31: 强维度对齐
| MA维度 | 激活值 | u1值 | 备注 |
|--------|--------|------|------|
| **Dim 3901** | **11.90** | **-0.81** | 🔥 强对齐 |
| Dim 2070 | 7.56 | 0.49 | ✅ |

→ Dim 3901同时是SVD主导维度和MA主导维度

### 机制推断
Mistral的MA与SVD存在一定关联：
- 整体对齐度: 中等（Layer 0: -0.38, Layer 31: 0.29）
- 关键维度对齐: Layer 31 Dim 3901强对齐
- 与Qwen（cos=0.99）相比，对齐关系更弱但仍存在
