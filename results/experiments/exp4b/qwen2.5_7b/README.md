# 实验4b: SVD对齐验证

## 实验目的
验证实际激活向量与SVD主导方向的对齐程度

## 实验方法
1. 计算Layer 3 MLP down_proj的SVD
2. 收集多个样本的激活向量
3. 计算激活与u1、u2、u3的余弦相似度

## 核心结果

| 向量 | 奇异值 | 与激活对齐 | 分析 |
|------|--------|-----------|------|
| **u1** | 17.03 | **0.994** | ✅ 完美对齐 |
| u2 | 6.45 | 0.016 | ❌ 无对齐 |
| u3 | 6.27 | 0.049 | ❌ 无对齐 |

## 结论

**✅ Qwen的MA与SVD主导方向完美对齐！**

- 所有样本与u1对齐都>0.99
- 与u2、u3几乎无对齐
- 证实MA由MLP down_proj的主导奇异方向产生

## 关键维度
- **Dim 458**: u1分量0.77（最大）
- **Dim 2570**: u1分量0.54

## 机制总结
```
MLP Layer 3 down_proj 权重矩阵
    ↓ SVD分解
主导奇异向量 u1 (σ₁/σ₂=2.64)
    ↓ 投影
Massive Activation (与u1对齐cos=0.994)
```
