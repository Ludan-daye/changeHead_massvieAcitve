# 实验4b: SVD与MA方向对齐测试

## 实验目的
测试MLP down_proj的左奇异向量u1与Massive Activation方向的一致性

## 实验方法
1. 提取各层运行时的激活向量
2. 对MLP down_proj做SVD分解，取左奇异向量u1
3. 计算MA向量与u1的余弦相似度
4. 分析Top维度交集

## 核心结果

### Layer 0（关键层）
| 指标 | 值 |
|------|-----|
| 余弦相似度 | **0.11** (弱) |
| MA最大值 | 12.44 |
| Top10维度交集 | **5个** |

- **MA Top维度**: Dim 2002(12.4), Dim 3080(-11.0), Dim 774(-11.0)
- **u1 Top维度**: Dim 2138(0.12), Dim 3950(-0.09), Dim 1673(0.09)
- **交集**: {774, 1673, 3950, 3124, 2138}

### Layer 31
| 指标 | 值 |
|------|-----|
| 余弦相似度 | **-0.14** (弱) |
| MA最大值 | 244.75 |
| Top10维度交集 | **4个** |

- **特别注意**: Dim 350同时是MA和u1的主导维度

## 结论

### 弱整体对齐，中等维度交集

| 指标 | Layer 0 | Layer 31 |
|------|---------|----------|
| 余弦相似度 | 0.11 | -0.14 |
| 维度交集数 | 5/10 | 4/10 |

**结论**:
- 整体余弦相似度较低，说明MA方向与SVD主导方向不完全一致
- 但Top维度有部分交集（约40-50%）
- 与Mistral相似：非强对齐，存在维度级关联
