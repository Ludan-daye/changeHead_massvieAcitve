# 实验2: 层贡献分析

## 实验目的
找出哪一层的Attention对抑制MA贡献最大

## 实验方法
1. 禁用所有Attention Heads
2. 逐层恢复单层的Attention
3. 测量恢复后的激活值变化
4. 找出抑制效果最强的层

## 核心结果

| 层 | 恢复后激活 | 分析 |
|----|-----------|------|
| **Layer 0** | **1,959** | 抑制最强（从7067降到1959） |
| Layer 1 | 5,421 | 有一定抑制 |
| Layer 2 | 6,788 | 抑制较弱 |
| 其他层 | ~7,000 | 几乎无抑制 |

## 结论

**Layer 0 的 Attention 抑制效果最强！**

- Layer 0 能将激活从7067降到1959
- 前3层有主要抑制作用
- 后层Attention对MA几乎无影响
