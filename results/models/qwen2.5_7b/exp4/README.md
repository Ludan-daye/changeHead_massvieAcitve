# 实验4: MLP SVD分析

## 实验目的
分析MLP down_proj层权重的SVD结构，寻找主导奇异方向

## 实验方法
1. 提取各层`mlp.down_proj`权重矩阵
2. 进行SVD分解: W = UΣVᵀ
3. 计算σ₁/σ₂比值判断是否有主导方向

## 核心结果

| Layer | σ₁ | σ₂ | σ₁/σ₂ | 主导方向 |
|-------|-----|-----|-------|---------|
| Layer 0 | 12.89 | 6.44 | 2.00 | ⚠️ 临界 |
| Layer 1 | 9.27 | 5.92 | 1.57 | ❌ 无 |
| Layer 2 | 12.00 | 6.47 | 1.85 | ❌ 无 |
| **Layer 3** | 17.03 | 6.45 | **2.64** | ✅ 有 |
| Layer 4+ | - | - | <2.0 | ❌ 无 |

## 结论

**Layer 3 有最强的主导奇异方向！**

σ₁/σ₂=2.64，第一奇异值显著大于其他，说明Layer 3的MLP存在特殊的几何结构。
