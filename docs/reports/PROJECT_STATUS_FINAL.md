**模型分类**:

|---------|-----|---------|------|
| **强SVD** | GPT-2 | ⭐⭐⭐⭐⭐ | 3/3层，R²=0.567~0.998 |

| **非SVD** | BLOOM, GPT-J, LLaMA2 | ⭐ | 所有层R²<0.04 |

**数学机制**:
```
massive_activation ≈ σ₁ × (h₂ · v₁) + bias
其中:
- σ₁: 最大奇异值（放大系数）
- h₂: MLP中间激活
- v₁: 第一左奇异向量（主导方向）
```

## 🔍 关键发现：两种MA产生机制

### **机制A: SVD几何对齐机制** ✅

**代表模型**: GPT-2, Qwen, OPT, Falcon

**特征**:
- MLP的down_proj矩阵第一奇异方向主导
- 激活向量与u₁高度对齐 (cos > 0.95 或 R² > 0.95)
- σ₁/σ₂ > 2.0（第一方向主导）
- V矩阵控制强（影响 -70%~-99%）

**数学表达**:
```
y_massive ≈ σ₁ · (v₁ᵀ σ(W₁ x_func + b₁)) · u₁ + b₂

其中:
- x_func: 功能词的embedding
- v₁: W₂的主右奇异向量（对功能词敏感）
- σ₁: 最大奇异值（放大倍数）
- u₁: 对应的左奇异向量（输出方向）
```

### **机制B: 非SVD机制** ⚠️

**代表模型**: BLOOM, Mistral, GPT-J, LLaMA2

**特征**:
- 无明显奇异方向主导 (σ₁/σ₂ ≈ 1.1-1.2)
- 激活与u₁对齐度低 (cos < 0.1)
- V矩阵影响较小或中等 (-18%~-70%)
- 可能源于其他机制（ALiBi位置编码、Sliding Window Attention等）

**可能机制**:
- **BLOOM**: ALiBi位置编码导致的残差累积 + Layer 28的多头协作效应
- **Mistral**: Sliding Window Attention的多头协作 + GQA+SwiGLU组合
- **GPT-J**: Parallel FFN架构的特殊性
- **LLaMA2**: 13B规模下的复杂多层交互
