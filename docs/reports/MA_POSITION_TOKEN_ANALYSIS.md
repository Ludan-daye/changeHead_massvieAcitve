# MA出现位置Token分析

## 实验目的
验证"MA出现在无语义连接词位置"的假设

## 实验方法
1. 对每个模型运行10个样本（seqlen=512）
2. 找出每个样本的Top5 MA位置
3. 统计这些位置对应的token类型

## Token类型定义
- **标点符号**: `, . ; : ! ? ( ) [ ]` 等
- **空白/换行**: 空格、`\n`、`\t` 等
- **功能词**: `the, a, of, to, in, on, and, or, is, are` 等
- **特殊token**: `<s>, </s>, <pad>` 等
- **实义词**: 其他有语义的词

## 汇总结果

| 模型 | 无语义词占比 | Top1类型 | Top1 Token |
|------|-------------|----------|------------|
| gptj_6b | **58.0%** | 功能词 | `' the'` |
| bloom_7b1 | **98.0%** | 功能词 | `' the'` |
| qwen2.5_7b | **40.0%** | 实义词 | `'\n\n'` |
| falcon_7b | **100.0%** | 空白/换行 | `' '` |
| mistral_7b_v03 | **100.0%** | 功能词 | `'and'` |
