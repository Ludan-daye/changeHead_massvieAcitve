# Exp4 示例图表说明 - Qwen2.5-7B

## 数据背景
- **模型**: Qwen2.5-7B
- **MA生成层**: Layer 3
- **Layer 3 特征**: σ1/σ2 = 2.64 (存在显著的主导奇异值方向)

## 生成的图表

### 1. Singular Value Decay Comparison (奇异值衰减对比)
**文件**: `qwen2.5_7b_Singular_Value_Decay_Comparison.png/pdf`

**内容**: 对比Layer 0, 1, 2, 3, 26的前20个奇异值大小

**观察点**:
- Layer 3 (MA层，红色) 的第一个奇异值显著大于其他层
- Layer 3: σ1=17.03，远大于σ2=6.45
- 其他层的奇异值衰减较为平缓，差异不明显

**结论**: MA生成层具有非常突出的主导方向（σ1远大于其他奇异值）

---

### 2. σ1/σ2 Ratio Comparison (σ1/σ2比率对比)
**文件**: `qwen2.5_7b_Sigma1_Sigma2_Ratio_Comparison.png/pdf`

**内容**: 对比不同层的σ1/σ2比率，评估主导方向的强度

**数据**:
- Layer 0: 1.23
- Layer 1: 1.69
- Layer 2: 1.19
- **Layer 3 (MA层): 2.64** ⭐
- Layer 26: 1.15

**参考线**: ratio=1.0表示无主导方向（σ1=σ2，各向同性）

**结论**: MA层的ratio显著高于其他层，表明存在强主导方向，可能与MA生成机制相关

---

### 3. Cumulative Energy Distribution (累积能量分布)
**文件**: `qwen2.5_7b_Cumulative_Energy_Distribution.png/pdf`

**内容**: 显示前k个奇异值累积能量占比（能量 = σ²）

**观察点**:
- Layer 3 (MA层) 的前1个奇异值已经占据大量能量
- 达到90%能量所需的奇异值数量：Layer 3最少
- 其他层需要更多奇异值才能达到90%能量

**结论**: MA层的能量更加集中在前几个主成分上，表明低秩结构

---

### 4. Layer 3 MA Layer Detailed Analysis (MA层详细分析)
**文件**: `qwen2.5_7b_Layer3_MA_Layer_Detailed_Analysis.png/pdf`

**内容**: 专门分析MA生成层（Layer 3）的SVD特性

**左图**: 奇异值绝对大小
- σ1 = 17.03 (极度突出)
- σ2 = 6.45
- 后续奇异值逐渐衰减

**右图**: 归一化奇异值（相对于σ1）
- 展示奇异值的相对重要性
- σ2/σ1 = 0.379 (红色虚线)
- 第二个奇异值仅为第一个的38%

**结论**: Layer 3存在一个极度主导的方向，可能与MA激活方向高度相关

---

## 关键发现

1. **MA层具有特殊的SVD结构**: Layer 3 (MA层) 的σ1/σ2比率(2.64)远高于其他层(1.15-1.69)

2. **主导方向假设**: MA生成可能与Attention权重矩阵的主导奇异值方向有关

3. **能量集中**: MA层的能量更加集中在前几个主成分，表明低秩特性

4. **对比其他层**: 非MA层的奇异值分布较为均匀，无明显主导方向
